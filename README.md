# 클로드 타운

이 맥북에서 도는 Claude Code 세션들을 2D 픽셀 사무실로 보여주는 로컬 도구입니다.

## 여는 법

- 앱으로 열기: `클로드 타운.app` 을 더블클릭합니다. 응용 프로그램 폴더나 Dock 에 끌어다 놓아도 됩니다.
- 브라우저나 Cursor 안에서 열기: `node server.mjs` 를 켜고 `http://localhost:4777` 을 엽니다. Cursor 에서는 명령 팔레트의 "Simple Browser: Show" 에 같은 주소를 넣으면 편집기 옆 탭으로 뜹니다.

앱 메뉴의 "보기"에서 "항상 위에 두기"(Cmd+T)와 "작은 창으로"(Cmd+1)를 쓸 수 있습니다.

## 화면 읽는 법

| 장소 | 뜻 |
| --- | --- |
| 작업실 책상 | 일하는 중인 세션입니다. 말풍선은 지금 하는 일, 대괄호는 최근에 쓴 도구입니다. |
| 머리 주위를 도는 주황 꼬마 | 그 세션이 부른 서브에이전트나 백그라운드 작업 수입니다. |
| 빨간 카펫(호출 벨) | 마스터의 답을 기다리며 멈춰 있는 세션입니다. 탭 제목에도 숫자가 뜹니다. |
| 휴게실 | 끝난 세션입니다. 하루 안에 끝났으면 커피를 들고 있고, 오래됐으면 잡니다. |
| 왕관 | 백그라운드 작업이 아니라 터미널에서 직접 연 세션입니다. |

캐릭터를 누르면 받은 요청, 토큰 수, PR 링크가 나오고 별명, 머리색, 피부색, 옷, 장식을 바꿀 수 있습니다. 꾸민 내용은 그 창(앱 또는 브라우저)에 저장됩니다.

## 동작 원리

`server.mjs` 가 `~/.claude/jobs/*/state.json`, `~/.claude/sessions/*.json`, 그리고 트랜스크립트 끝부분을 읽어 `/api/sessions` 로 내보내고, `index.html` 이 2초마다 받아 캔버스에 그립니다. 읽기만 하며 `127.0.0.1` 에만 열립니다. 이 파일들은 Claude Code 의 공개 규격이 아니므로 버전이 오르면 읽는 부분을 손봐야 할 수 있습니다.

`server.mjs` 나 `index.html` 을 고친 뒤에는 `./build-app.sh` 를 다시 돌려야 앱에 반영됩니다.
